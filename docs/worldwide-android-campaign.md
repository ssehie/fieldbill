# FieldBill Worldwide Android Campaign

Last updated: 2026-05-26

## Campaign Goal

Drive real Android installs and feedback for FieldBill without cutting a new build and without using fake, incentivized, or spammy promotion.

Primary link:

`https://play.google.com/store/apps/details?id=com.fieldbill.app`

Landing page:

`https://ssehie.github.io/fieldbill/android/`

## Current Warning

Public search currently surfaces `fieldbill.app`, which appears to be a different FieldBill product. Do not use that domain for this app unless ownership is verified later.

Use the package-based Google Play link and the GitHub Pages landing page above.

## Non-Negotiable Rules

- Do not buy installs, ratings, or reviews.
- Do not ask for review swaps.
- Do not offer money, perks, unlocks, or gifts for ratings or reviews.
- Do not post the same link repeatedly across unrelated communities.
- Do not send unsolicited bulk SMS.
- Do not claim Google affiliation, Play ranking, awards, or "No. 1" status.
- Disclose that Steve built the app when posting personally.
- Ask for practical workflow feedback, not fake praise.

## Global Positioning

FieldBill is a simple Android invoice app for independent contractors and field-service workers who need to create and send invoices from the job site.

Best-fit users:

- solo contractors
- handymen
- mobile mechanics
- cleaners
- lawn care workers
- appliance repair workers
- small remodel crews
- small plumbing/electrical/HVAC operators
- maintenance workers

## First 48 Hours

1. Confirm the public Play link opens outside tester-only mode.
2. Publish or verify the GitHub Pages landing page at `/android/`.
3. Send 20 direct one-to-one messages to real contractor contacts.
4. Post once in one local Facebook or trade group that allows feedback requests.
5. Post once in `r/androidapps` only if account/rules fit; that subreddit has explicit self-promo limits.
6. Submit to Product Hunt if screenshots and Play link are public.
7. Log every post, message, reply, install signal, objection, and feature request in `docs/worldwide-outreach-log.csv`.
